## 📌 Feature Prioritization & Architecture

| Feature | Impact & Priority | Description |
| :--- | :---: | :--- |
| **Complaint Submission Portal** | ⭐⭐⭐⭐⭐ | Multi-category grievance portal with unique Ticket ID generation (`UDN-XXXX`), urgency grading (Normal to Critical), anonymous submission toggle, and photo proof upload. |
| **Real-Time Status Tracker** | ⭐⭐⭐⭐⭐ | Visual 4-step progress pipeline (*Submitted ➔ Under Review ➔ In Progress ➔ Resolved*) with instant lookup, authority remarks, and 5-star resolution feedback. |
| **UDAAN Sahayak (AI Chatbot)** | ⭐⭐⭐⭐⭐ | 24/7 intelligent bilingual campus guide (Hindi + English + Hinglish) capable of tracking tickets directly, answering campus queries, and pre-filling complaints. |
| **Interactive Campus Map** | ⭐⭐⭐⭐ | Vector SVG campus blueprint with active issue hotspots, building inspector, and 1-click location-specific issue reporting. |
| **Campus Analytics & Dashboard** | ⭐⭐⭐⭐ | Real-time administrative console with live KPIs, category/status filters, and **Admin Demo Mode** to test resolving issues live. |
| **Bilingual Support (Hindi / English)** | ⭐⭐⭐⭐ | 1-click language switcher (`🌐 हिंदी / EN`) localizing all titles, forms, chatbot greetings, and tracker data. |
| **Dark Mode Experience** | ⭐⭐⭐ | Sleek theme switch with high-contrast night aesthetics and persistent storage. |

## 🏆 5 Top Features That Impress Hackathon Judges (Hack Day Jaunpur / Hacktoberfest)

1. **Dual Admin / Student Live Simulation Mode**:
   - Judges can toggle **Admin Demo Mode** on the dashboard to change ticket statuses live (e.g. from *In Progress* to *Resolved*), immediately watching the Status Tracker, Map, and KPIs update in real-time.
2. **Instant Tracking Ticket ID & Copy / Share**:
   - Generates an institutional ticket (e.g., `UDN-1024`) with copy-to-clipboard, estimated turnaround time, and direct link into the tracker.
3. **Emergency SOS & Helpline Integration**:
   - 1-click emergency sheet for Proctor security, Anti-Ragging toll-free cell (`1800-180-5522`), Women safety helpline (`1090/112`), and campus dispensary.
4. **Pre-Seeded Authentic Campus Data**:
   - Pre-loaded with realistic regional university complaints (WiFi dead zones in Library, Hostel RO water cooler, Lab projector, Street lights) so the demo never looks empty.
5. **Printable / CSV Grievance Audit Report**:
   - 1-click export of an official campus grievance audit report ready for administrative presentation to College Principals & Deans.

## 💻 How to Run

1. Open `index.html` in any modern web browser (Edge, Chrome, Firefox, Safari).
2. Alternatively, run using VS Code Live Server or python http server:
   ```bash
   # In terminal
   python -m http.server 3000
   ```
3. Open `http://localhost:3000`.
